# PureSupp - Мобильное приложение для проверки чистоты и реального состава БАДов
**Бизнес-модель:** B2C
## Elevator Pitch
Многие люди принимают БАДы, не подозревая, что в них могут содержаться тяжелые металлы или примеси, а реальное содержание активного вещества часто ниже заявленного. PureSupp — это мобильный сервис, который позволяет покупателю отсканировать штрих-код продукта и мгновенно получить отчет о его реальной чистоте и безопасности на основе независимых лабораторных данных. Мы помогаем осознанным потребителям выбирать только проверенные добавки, экономя их деньги и сохраняя здоровье.
## Lean Canvas
| **Проблема**             | 1. Недоверие к качеству БАДов (примеси, тяжелые металлы).<br>2. Отсутствие прозрачности в составах.<br>3. Риск купить «пустышку» с низким содержанием активного вещества.                                 |
| **Сегменты клиентов**    | 1. Биохакеры и люди, следящие за питанием.<br>2. Профессиональные спортсмены.<br>3. Родители, покупающие витамины детям.                                                                                  |
| **Уникальное ценностное предложение** | «Прозрачность в каждой капсуле»: мгновенный доступ к результатам независимых лаб-тестов, которых нет на этикетке.                                                                                          |
| **Решение**              | Приложение-сканер со встроенной базой данных лабораторных анализов и рейтингом чистоты продуктов.                                                                                                         |
| **Каналы**               | 1. Магазины приложений (App Store/Google Play).<br>2. Реклама у фитнес-блогеров.<br>3. Тематические форумы и сообщества (Reddit, iHerb-чаты).                                                             |
| **Потоки выручки**       | 1. Freemium (базовый отчет бесплатно, подробный хим. состав — по подписке).<br>2. Партнерские ссылки на покупку «чистых» брендов.                                                                         |
| **Структура расходов**   | 1. Разработка и поддержка приложения.<br>2. Оплата услуг независимых лабораторий для закупки и тестов образцов.<br>3. Маркетинг.                                                                          |
| **Ключевые метрики**     | 1. Количество сканирований в день.<br>2. Retention (возвращаемость пользователей).<br>3. Конверсия в платную подписку.                                                                                    |
| **Скрытое преимущество** | Эксклюзивные контракты с независимыми лабораториями и база данных, которую сложно быстро скопировать.                                                                                                     |
